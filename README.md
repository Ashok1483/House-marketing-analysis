# House Market Dashboard

## Project Overview
Developed an interactive Power BI dashboard to analyze housing market data and identify trends in property prices, locations, and housing characteristics.

## Problem Statement
Analyzing housing market data manually can make it difficult to understand property price trends, compare locations, and identify important patterns. This project aims to simplify housing market analysis through interactive visualizations.

## Solution
Created an interactive Power BI dashboard to visualize housing market data and provide meaningful insights into property prices and market trends.

- Analyzed housing prices across different locations.
- Compared property prices and housing characteristics.
- Created interactive visualizations and KPI cards.
- Used filters and slicers to explore the data.

## Technologies Used
- Power BI
- Power Query
- DAX
- Microsoft Excel

## Key Features
- Interactive dashboard with filters and slicers.
- Housing price analysis.
- Location-based comparisons.
- Visual representation of housing market trends.
